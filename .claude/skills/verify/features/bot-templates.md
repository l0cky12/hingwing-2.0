# Bot templates

The Connectors screen's fifth tab, Templates, sits after Tools and shows "Templates 3" at once, without waiting on Hermes. It opens like the other tabs, from the Connectors button or Ctrl+Shift+M, then the tab. Above the cards it says "Start a new bot from a template." The header hides "Configuring:" on this tab, because a template makes a new bot rather than changing the open one.

Three cards lie two to a row, and one to a row in a narrow window. Each shows the template's own face, drawn as the New bot form draws one (an amber hexagon for Bot Builder, a teal seal for Deep Researcher, a plum cloud for Nightly Repo Auditor), the template's name, "Template", a one-line summary, "Turns on: " and the tools in plain words, each kept whole on one line, and "Approval: Manual" or "Approval: Smart". Nightly Repo Auditor adds "Runs nightly at 2:00 AM". Each has a Use template button named "Use template <name>".

- **Bot Builder.** "Describe a bot, and it makes the bot for you." Turns on Terminal, Files, Ask you questions, Skills and To-do list. Manual approval.
- **Deep Researcher.** "Researches a question across many sources and writes a report with sources." Turns on Web, Browser, Helpers, Files, To-do list, Memory and Ask you questions, with no Terminal. Smart approval.
- **Nightly Repo Auditor.** "Checks a code repository every night and reports problems." Turns on Terminal, Files, Web and Memory. Smart approval. Runs nightly.

Use template opens a modal dialog titled "Use template: <name>" with focus in the Bot name field, which holds the template's id ("bot-builder", "deep-researcher" or "nightly-repo-auditor"), because Hermes takes only lowercase letters, numbers, "-" and "_" for a profile's name. It can be edited. The auditor's dialog also has Repository folder, a required text field with the hint "A folder path on the computer Hermes runs on, not on this one.", and Run time, a time field that starts at 02:00. A "What it sets up" box lists the start of the personality, the tools, the approval mode as "Manual: Asks you before every risky command." or "Smart: Runs safe commands, refuses dangerous ones, asks about the rest.", and for the auditor the schedule, which follows the Run time field and reads "Pick a run time" while the field is empty. Cancel and Escape close the dialog and put focus back on the Use template button. Escape does not also close the Connectors screen.

Create bot is enabled once the name is not blank and not a bot Hermes already lists, and for the auditor the folder is not blank and the run time is a time. A name that is taken shows "There's already a bot called <name>." under the field, and a name Hermes refuses shows Hermes's reason there. Create bot makes the profile (`profiles.create`, with the template's summary as its description and its persona as its SOUL.md), stores the card's face as its picture (`profiles.set_asset` of `avatar`, a 512 px PNG), so the new bot's avatar is that face wherever it shows, then turns on its tools (`profiles.configure` with `enabled_toolsets`), sets its approval mode (`config.set` of `approval_mode` for that bot) and, for the auditor, adds the job "Nightly audit" (`cron.manage` add, with the cron line `0 2 * * *` for 02:00 and a prompt that names the folder). While it runs the button reads "Creating…" and the fields are disabled. On success the dialog and the Connectors screen close and the new bot opens. The auditor's job shows under Routines in the bot's details as "Every day at 02:00". If a step after the profile fails, the bot is still made, but nothing opens yet. The dialog stays open in bot and chat mode, with its fields disabled, and says "Hermes made <bot>, but not everything was set up:" over a list of the failed steps in words, such as "the nightly job wasn't added." with Hermes's reason after it. Its buttons are Close and "Open <bot>", which opens the new bot.

## Sub-features

- `bt-cards` shows the Templates tab in dark and light at 1440x900 and in a narrow window.
- `bt-builder` opens Bot Builder's dialog and closes it with Escape.
- `bt-auditor` opens the auditor's dialog, types a folder and closes it with Cancel.
- `bt-fields` checks when Create bot is enabled: the auditor's folder and run time, and a taken name.
- `bt-create-builder` presses Create bot for Bot Builder, checks its five gateway calls and that the new bot opens with the template's face.
- `bt-create-auditor` presses Create bot for the auditor, checks its calls and the job under Routines.
- `bt-refused` sends a name Hermes refuses, keeps the dialog open at the Bot name field, then makes the bot with a name it takes.
- `bt-warned` makes the auditor on a Hermes that cannot schedule jobs, shows the warning in the dialog, and opens the bot from it.
- `bt-warned-chats` does the same from chat mode, where the Bots column is not shown.

## How to get to it (user POV)

- Open Connectors (the grid-plus button at the bottom right of the sidebar, or Ctrl+Shift+M) and choose the Templates tab, or press Right from the Tools tab.

## Gotchas

- Every tab's panel stays in the page while hidden, so `see` can match another tab's text. The template names appear only on this tab.
- A `type` step moves focus to the field it fills, so check `focused textbox "Bot name"` before typing.
- Every recipe that clicks Create bot adds `--yolo off --approvals manual` (or `smart`), so the gateway answers `config.set` of `approval_mode`, and the auditor's adds `--cron fixtures/cron/none.json`, so it answers `cron.manage`. Without them those calls are unknown methods, which `bt-warned` uses.
- The new bot is listed by its id, such as "nightly-repo-auditor", because a template sets no display name.
- `called` is checked again at the end of the run, so a later call that also fits the JSON fails an earlier "0". Name the call by its bot.
- The auditor's card also says "Runs nightly at 2:00 AM", so `absent "Runs nightly at"` fails behind the open dialog.
