# Bots sidebar

A column at the left of the window lists the bots of the Hermes that Highwing is connected to. The default bot sits at the top as a large avatar with a star. Bots pinned in Hermes sit under "Pinned" below it. The other bots sit under their sections, with the bots in no section last under "Unassigned". Bots hidden in Hermes sit at the bottom under a collapsed "Hidden (N)", drawn at lower emphasis when it is open. Each row shows the bot's initial, its name and one line from the chat a click on it opens. The bot whose chat is open is the selected one. Search narrows the list by name. The chat sits to the right of the column.

## Sub-features

- `bots-roster` lists the bots Hermes names, in their sections, with the default bot selected.
- `bots-marks` draws pinned bots under Pinned and hidden bots under Hidden (N), which opens for a search that finds a hidden bot, for an open hidden bot, and when every bot is hidden, and which a click always closes.
- `bots-select` selects the bot whose chat a click opened. [Open a bot](./open-a-bot.md) covers the chat itself.
- `bots-search` swaps the header for a search box, narrows by name, says when nothing matches, and closes on Escape, Close search, or leaving the empty box.
- `bots-keys` keeps Escape and the paging keys to the search box while it has focus.
- `bots-older` says "This Hermes can't list its bots." on a Hermes with no `profiles.list`, and asks once.
- `bots-offline` keeps the last roster while the connection is down.
- `bots-new` shows the plus menu's New bot… row as unavailable, with the reason, and still reachable by keyboard when Hermes cannot list its bots. [Create a bot](./create-a-bot.md) covers it while it works, and [Group chats](./group-chats.md) the rest of the menu.
- `chat-unchanged` proves the chat column draws the same pixels before and after a change.
- `chat-narrow` proves the chat's compact layout follows its column, not the window.

## How to get to it (user POV)

- Open Highwing with a connection to Hermes. The column is at the left of the chat.

## Driving it with highwing-verify

Preconditions:

- `--profiles fixtures/profiles/roster.json` gives the scripted gateway the six bots of the user's own Hermes: Emu as the default bot, dr eggbot under New section, and Research, Timothy · CEO, Hermes and highwing unassigned. `fixtures/profiles/marks.json` gives it twenty, enough to scroll: the default bot Hermes is hidden, Researcher is pinned, Old Helper is hidden, and Test Bot is both pinned and hidden. `fixtures/profiles/edge.json` gives it thirty-one, one of them hidden, with a joined emoji and a flag as names, a long title over a short display name, a profile name with a space, a hex colour and another CSS colour, a Bot Chat beside a newer chat, keys outside `hermes-bots`, and a second default bot. Without `--profiles` the gateway refuses `profiles.list` as unknown.
- `chat-unchanged` needs a build from before your change. Take its shots first.

- **Roster and select.** Run `$H run --fixture fixtures/errand.jsonl --profiles fixtures/profiles/roster.json --run bots wait live wait bots current button "Emu, default bot" shot roster click button "Timothy · CEO" current button "Timothy · CEO" called session.resume '{"profile":"timothy"}' 1 shot selected quiet`. `roster.aria.txt` holds `complementary "Bots"` with `heading "New section"` before `heading "Unassigned"`. The one `session.resume` for Timothy shows the selected bot is the one whose chat opened.
- **The approved layout.** Run `$H run --fixture fixtures/errand.jsonl --profiles fixtures/profiles/roster.json --run bots-approved wait live wait bots click button Research press Tab focused button "Details for Research" press Tab press Enter current button "Timothy · CEO" focused button "Timothy · CEO" shot bots-approved quiet`, then `$H compare bots-approved`. Tab and Enter open Timothy · CEO with the keyboard, so the row carries the focus ring the approved layout shows. Left of x=288 the shot matches `docs/design/reference/bots-sidebar.png` pixel for pixel, except the mode switch's chevron after "Bots" in the heading, 62 pixels that the reference predates. Right of it the reference shows the settled errand, from when a click opened no chat, and the shot shows Timothy's Bot Chat.
- **Pinned and hidden.** Run `$H run --fixture fixtures/errand.jsonl --profiles fixtures/profiles/marks.json --run bots-marks wait window wait live wait bots current button Hermes see "Hidden (3)" count button "Old Helper" 1 shot launch-hidden-default click button "Hidden (3)" count button "Old Helper" 0 count button Hermes 0 shot hidden-collapsed click button Editor current button Editor click button "Search bots" type "Search bots" old count button "Old Helper" 1 count button Editor 0 shot search-finds-hidden quiet`. - **Paging keys stay in the search box.** Run `$H run --fixture fixtures/long-turn.jsonl --profiles fixtures/profiles/roster.json --run bots-keys wait live wait bots type "Message Hermes" @request click button Send wait approval pinned click button "Search bots" press PageUp press Home press End press PageDown pinned gone button "Jump to latest" click button "Close search" press PageUp see "Waiting for your OK" quiet`. - **Many bots, long thread.** Run `$H run --fixture fixtures/long-turn.jsonl --profiles fixtures/profiles/edge.json --run bots-edge wait live wait bots type "Message Hermes" @request click button Send wait approval pinned inview group "Run this command?" inview button "Hermes Agent, default bot" count button "Retired helper" 0 count button Retired 0 see "Hidden (1)" count button "The exceptionally long-named quarterly planning and forecasting assistant" 1 shot edge click button Tailor current button Tailor inview button Tailor pinned shot edge-end quiet`. The click on Tailor opens Tailor's chat, so `edge-end` shows that chat and not the errand.
- **Forced colors.** Run `$H run --fixture fixtures/errand.jsonl --profiles fixtures/profiles/roster.json --forced-colors --run bots-forced wait live wait bots shot roster click button "Timothy · CEO" current button "Timothy · CEO" shot selected click button "Search bots" shot search quiet`. Each avatar and the star have a `CanvasText` border, and the selected row has a `Highlight` left edge.
- **Narrow.** Run `$H run --fixture fixtures/errand.jsonl --profiles fixtures/profiles/roster.json --size 680x860 --run chat-narrow wait live wait bots inview button Send type "Message Hermes" @request click button Send wait approval inview button "Run once" inview button highwing shot narrow quiet`. At 680 px the sidebar still shows and leaves the chat 392 px.
- **Narrower than 680 px.** Run `$H run --fixture fixtures/errand.jsonl --profiles fixtures/profiles/roster.json --size 600x860 --run chat-tiled wait live gone complementary Bots inview button Send type "Message Hermes" @request click button Send wait approval inview button "Run once" shot tiled quiet`. Below 680 px the sidebar hides and the chat takes the whole window, as it did before the sidebar existed. A tiling compositor can size the window this small.
- **Chat unchanged.** Before your change, run `$H run --fixture fixtures/errand.jsonl --profiles fixtures/profiles/roster.json --chat-only --run chat-before wait live shot open type "Message Hermes" @request click button Send wait tool-running shot tool-running wait approval shot approval click button "Run once" wait settled shot settled`. After it, run the same steps with `--run chat-after`. Then run `node .claude/skills/verify/scripts/chat-parity.mjs /tmp/highwing-verify/chat-before /tmp/highwing-verify/chat-after`. It must end in `PASS`. Add `--size 600x860` to both runs for the compact layout.

## Gotchas

- A shot of the whole window does not line up with the design C references, and `forced-colors-check.mjs` cannot find the thread in it. Run those recipes with `--chat-only`.
- `chat-parity.mjs` reaches zero only when both runs place the chat column at the same spot in the window. A build with no sidebar draws the same layout as a build with one, yet at 600 px and 892 px a few anti-aliased pixels differ by 1 to 14 levels of 255, because the column sits 288 px further right. At 1180 px the two match exactly.
- `current` reads `aria-current`. An ARIA snapshot does not print it.
- A click on a bot opens its chat, so a recipe that clicks one mid-story leaves the story's chat. Click the default bot to come back to it.
- The search box and the Search bots button share the label "Search bots". Only one of them is on the page at a time.
- While a row of the plus menu is unavailable it is `aria-disabled`. Playwright treats that as disabled, so `click menuitem "New bot…"` waits until the timeout. Reach it with the arrow keys, Home or End.
- PageUp, PageDown and End page the chat while focus is on a bot. The bot list has no paging keys yet.
- The roster's previews come from the fixture header and do not change when the story runs.
- This machine has no emoji font, so the emoji names of `edge.json` draw as empty boxes in a shot. `roster-view.test.ts` proves the initial is the whole emoji.
