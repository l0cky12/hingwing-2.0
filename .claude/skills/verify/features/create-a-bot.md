# Create a bot

New bot, the plus in the Bots column's header, opens a dialog with four fields: Name, Description, Model and Persona. Above Name sits the bot's face, an avatar button with what is picked in words beside it, such as "Slate drop, picked from the name". Change picture opens a popover named Bot picture over the fields, with four tabs: Shape (Auto, 12 shapes, 12 colors and Surprise me), Generate (a prompt for Hermes's image model), Upload (main's file picker) and Pet (the pets Hermes lists). Create makes the bot in Hermes (`profiles.create`), stores the face as its picture (`profiles.set_asset`, a 512 px PNG, or an upload as main checked it), lists it under Unassigned and opens it, as a chat that has no message yet. A picture Hermes does not keep is one more warning in the sidebar, and the bot exists all the same. The name is checked against the listed bots before anything is sent, and Hermes's own reason for a name it refuses shows under the field. Any other refusal shows above the buttons, and every typed value stays. Hermes's warnings show in the sidebar in words, and the bot exists all the same. While the link is down, or Hermes has not listed its bots or cannot create one, New bot stays focusable and says why.

## Sub-features

- `create-bot-dialog` opens the dialog with its four fields and Create disabled while Name is blank, and closes it with Escape or Cancel.
- `create-bot` fills the form, sends the typed values, lists the new bot, and opens it.
- `create-bot-taken` stops a name the roster has, a slash, and `default` in any case before any call.
- `create-bot-warnings` shows the warnings of a create in the sidebar, and clears them on the next bot picked.
- `create-bot-refused` shows Hermes's reason for a name under Name, and keeps the typed text.
- `create-bot-unsupported` shows a Hermes that refuses the call above the buttons, and keeps the typed text.
- `create-bot-look-open` shows the name's Auto face with Name focused, and Change picture opens the popover on the Shape tab with focus on it.
- `create-bot-look-shape` picks a shape and a color, and Surprise me picks another of each.
- `create-bot-look-auto` shows the Auto shape following the typed name, the same for the same name in any case, and keeping the color picked.
- `create-bot-look-generate` asks the image model with a busy state, shows the drawn picture, and takes a shape again.
- `create-bot-look-generate-none` and `create-bot-look-generate-older` say how to turn an image model on, for a Hermes with none and one without the call.
- `create-bot-look-generate-fails` shows the model's failure in the tab and keeps the face.
- `create-bot-look-upload` takes a picked file and sends it as main checked it.
- `create-bot-look-upload-refused` shows the limit for a file that is not a picture, and keeps the face.
- `create-bot-look-pet` lists 24 pets with the curated ones first, reads only the thumbs shown, searches, picks a pet, disables one with no picture, and says when nothing matches.
- `create-bot-look-no-pets` and `create-bot-look-pets-older` say so for a Hermes that lists no pets and one without the call.
- `create-bot-look-escape` closes the popover with Escape or a click outside and keeps the dialog, then Escape closes the dialog with nothing sent.
- `create-bot-look-create` presses Create with the popover open, and sends `profiles.create` and then `profiles.set_asset` for the new bot, which the sidebar draws.
- `create-bot-look-refused` shows a picture Hermes did not keep as a sidebar warning, with the bot made and drawn with its letter.

## How to get to it (user POV)

- Press the plus in the Bots column's header, or Tab to it and press Enter.

## Driving it with highwing-verify

Preconditions:

- `--profiles fixtures/profiles/roster.json` gives the gateway the six bots, and makes it answer `profiles.create` as Hermes does. `--models fixtures/models/three.json` gives the Model list its three models, which Hermes reads from the profile's own config when no chat is open.
- The bot is made as the lowercase name, so Rae shows as `button "rae"`. A new bot has no Bot Chat and no chats. A chat made in it answers `<profile>: <text>`.
- `called profiles.create '{...}' <n>` reads the params the app sent. The gateway records them in `gateway-calls.jsonl`.
- The face is named in the words beside it, so `see` proves which: a blank name and Rae get a slate drop, Sam a sparkle and Ledger a pill. `--images` and `--pets` (see SKILL.md) give the Generate and Pet tabs what Hermes answers. `--pick-file` stands in for the file dialog of the Upload tab.

## Gotchas

- `select Model <option>` waits for the option, which is how a recipe waits for the model list. The list is read when the dialog opens, so a `shot` taken at once shows only "Hermes's default".
- The name Hermes keeps is the lowercase one, so the typed `Rae` is `rae` in the Bots column, the top bar and `called`.
- Without `--profiles` the gateway has no `profiles.create`, and the Bots column says the Hermes cannot list its bots, so New bot is unavailable. [Bots sidebar](./bots-sidebar.md) covers that.
- `called profiles.create '{}' 0` is checked again when the steps end, so it also fails on a call made by a later step.
- `see "..."` matches the dialog, the sidebar and the chat alike. Use `count` on the dialog to tell the dialog is still open.
- The dialog's `showModal()` makes the rest of the page inert, so a step that clicks outside it waits until the timeout.
- The popover covers the fields, so a step that clicks Name or another field while it is open waits until the timeout. Close it first, or click the dialog's title.
- A pet's tile is disabled until its thumb arrives, which `click` waits for. `called pet.thumb` is checked again when the steps end, so count every thumb the run shows.
- Every create now sends a picture, so a run that creates a bot also sends one `profiles.set_asset`.
