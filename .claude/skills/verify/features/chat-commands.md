# Chat commands

The user types `/btw <question>` to ask beside the chat, `/bg <prompt>` to run a prompt apart from it, and `/compress [focus]` to summarise the older turns. The slash menu offers all three. A side question or a background prompt sends its words to Hermes and leaves the turns as they were. A side question's answer joins the thread after the turn current when it came, and a background prompt's answer shows in a card above the composer, as [Side questions](./side-questions.md) covers. A compression shows Hermes's report under the composer, and the thread is then read again from what Hermes stores. Another client turns the chat's own YOLO on in the replay, since the window has no switch for it. `@` and letters list the chat's files through #112's `completePath`, which the replay's header answers. The Thinking pill sets the effort and fast mode with `tune`, and the folder chip moves the chat with `move`. Export is a chat row's More menu, as [Chat list](./chat-list.md) covers. In the replay below another client makes it, at the point the story waits for it.

## Sub-features

- `commands-btw` sends a typed `/btw` line as `prompt.btw` with the words alone, and shows the answer in the thread after the second turn.
- `commands-bg` sends a typed `/bg` line as `prompt.background`, and shows the answer in a "Background prompt" card.
- `commands-compress` sends a typed `/compress` line as a `compress` mutate with its focus, shows the report, and reads the chat again.
- `commands-complete` lists `notes.md` under Files for `@no`, from the `complete.path` reply the fixture's header holds.
- `commands-thinking` sets the effort with a `reasoning` mutate and fast mode with a `config.set` of `fast`, from the Thinking pill's popover.
- `commands-folder` moves the chat with a `workspace` mutate from the folder chip's field, and the chip then names the new folder.
- `commands-elsewhere` shows nothing new for the export call another client makes, and keeps the thread whole.

## How to get to it (user POV)

- Type `/btw`, `/bg` or `/compress` in the "Message Hermes" box, then words, and press Send.
- Click the effort pill in the composer's toolbar row (it reads "Default", and is named "Effort: Default"), then a level or the Fast switch.
- Click the folder chip in the composer's toolbar row (it reads "hermes-proto-work", and is named "Folder: /tmp/hermes-proto-work"), type a folder in "Folder on the Hermes machine", and press Move.

## Gotchas

- Each window call must reach the gateway while the story waits for it. A step the window cannot make stalls the story for its recorded pause of 1.5 s, so the fixture records the calls the window makes before the ones it leaves to another client.
- Wait for `gone button Stop` before the second message. The first reply's opening words show while its turn still runs. Under load a second message sent then gets no reply, and the story stalls at `said "docs/plan.md has two parts"`.
- Do not press Escape before Send. The slash menu is open only while the box holds `/` and a name with no space, so a whole typed line never opens it, and Escape in the box closes the newest side card.
- The compression's `session.updated` starts a rebuild, so `session.resume` with `display_projection` is sent twice in all.
- The compression stores the second turn's rows again under new ids, so the rebuild finds no row the side question's turn had. Its answer moves to the newest turn, which here is that same second turn.
