# Edit a bot

Each bot row in the Bots column, and the default bot, has a Details button beside it. It shows while the pointer is over the row and while it has keyboard focus. It opens a dialog named by the bot's name, with the bot's picture, Upload picture and, for a bot with a picture, Remove picture, then Name, Description and Persona filled from Hermes (`profiles.describe` and `profiles.list`). Save sends only the fields that changed in one `profiles.configure` call, and closes with no call when nothing changed. A rename writes the Bots plugin's record back whole with the new title, so the sidebar row and the chat's top bar show the new name and the open chat stays open. Upload picture asks main for a PNG, JPEG or WebP of 2 MB or less and sends it at once with `profiles.set_asset`. Remove picture sends `clear` at once. Where Hermes has a picture for a bot, its avatar draws it in place of the letter. A file that is not such a picture shows the limit in words and sends nothing. When the name changed elsewhere since the dialog read it, the form says "This bot changed elsewhere." and loads what Hermes holds now.

## Sub-features

- `edit-bot-details` opens the dialog named by the bot, with the three fields filled and no Model field.
- `edit-bot-rename` renames the open bot, and the sidebar row and the top bar show the new name over the same chat.
- `edit-bot-picture` uploads a PNG, draws it in the sidebar row, removes it, and draws the letter again.
- `edit-bot-not-a-picture` and `edit-bot-too-big` refuse a text file and a PNG one byte over 2,000,000 bytes, in words, with no call.
- `edit-bot-clash` shows a clash and reloads the fields, and a second Save at the new revision is kept.
- `edit-bot-keyboard` reaches a row's Details button with Tab, which shows it.

## How to get to it (user POV)

- Point at a bot row in the Bots column and press the pencil at its right end.
- Or Tab from a bot row to its Details button, which shows while it has focus, and press Enter.

## Driving it with highwing-verify

Preconditions:

- `--profiles fixtures/profiles/rae.json` lists the six bots of `roster.json` and Rae, in New section. Rae's description is "Writes the weekly report", her persona is "You write short, plain reports for the team.", and her name has revision 2.
- `--pick-file <path>` stands in for the file dialog. A run without it shows the real dialog, which no step can answer.
- The too-big file is made at run time, so the repo holds no 2 MB file: `node -e "const fs=require('fs');const b=Buffer.alloc(2000001);fs.readFileSync('fixtures/pictures/rae.png').copy(b);fs.writeFileSync('/tmp/highwing-verify-oversize.png',b)"`. It starts with PNG bytes, so only its size is wrong.
- `avatar <name> picture|letter` reads what a sidebar row's avatar draws.

## Gotchas

- The dialog opens once `profiles.describe` answers, so wait on `see "Upload picture"` before a `count` or `value` step.
- An `alert` has no accessible name, so `count alert "" 1` counts it.
- `called` is checked again when the steps end. Use `reached` for a call a later step repeats with more keys, as Remove picture repeats `{"name":"rae","asset":"avatar"}`.
- The top bar's heading is `Hermes <bot> · <chat>` for a chat with a title.
- The Details button is a sibling of its row, so a Tab from a row lands on it before the next row.
- `--configure-clash` plays one rename from elsewhere ahead of the first rename, not ahead of a persona-only or description-only Save.
