# Settings

The top bar's Settings button, or Open Settings in the Ctrl+K palette, opens Settings in the chat column. The sidebar stays beside it, so a Bots or Chats pick changes it live. The bar reads "Hermes Settings" with Close at its right, and the page holds a section list on the left. General holds Appearance, Password managers, Sidebar and Keyboard shortcuts. Permissions says commands are approved on the composer. Hermes machine holds the connection. Usage shows what Hermes reports, or that this Hermes does not report usage. About shows the app version and the Hermes version. Connection names the machine Highwing talks to: its short name, the full name in mono when it says more, and an Online pill, or the link's own words in place of the mono line with the banner's Retry, Start Hermes or Sign in. Change opens the editor in the same card: "Where Hermes runs" as Tailnet machine, Web address or This computer, the field the picked one asks for, "Hermes machine" or "Gateway address", and a footer with Cancel and Connect. [Connect by URL](./connect-by-url.md) covers the web address. A check shows its step in the footer, and a failure shows its alert under the field while the current connection stays Online. Cancel folds the editor, or stops a check. Escape in the editor does what Cancel does while the form takes input, so the first Escape folds it and the next closes Settings. A check that passes folds the editor on the new machine, puts focus on Change and says "Highwing now uses the Hermes on <machine>." Appearance picks the theme: System, Light or Dark, as [Theme](./theme.md) covers. Password managers sets up 1Password and Bitwarden for each bot, as [Password managers](./password-managers.md) covers. Sidebar picks the left column, and Keyboard shortcuts lists Ctrl K, Ctrl comma, Ctrl N and Ctrl F. Ctrl comma opens Settings from a chat, and leaves Settings open when it is already open. Close or Esc goes back to the chat and puts focus on the Settings button. A popover left open in the chat Settings hides, such as Folder, leaves Escape to Settings, and is still open when the chat comes back. A sidebar or palette pick of a bot or chat closes Settings and opens it, and so do a notification click and a chat link. Main closes Settings before any open, and stops a running check as Close does. While it saves a new connection it refuses the open, and nothing moves: the palette comes back with its query and main's reason. The bot menu opens in the sidebar beside Settings, takes the first Escape, and its Open chat and New chat close Settings as any open does, while a pin or a hide leaves it up. A group chat's row closes Settings and opens the group, with its members and the Settings button in the top bar. A bot or group chat made from the sidebar stops a running check first, as Cancel does. It closes Settings once Hermes has made it, if the live connection is still the one it was made on, and one Hermes refuses leaves Settings up. A palette pick that leaves Settings up, such as Reconnect, puts focus on Change, never on the composer Settings hides. Main refuses a chat command the window sent for an older connection, so a pick from the old sidebar never reaches the new machine. The connection banner and the preview pane stay hidden while Settings is open.

## Sub-features

- `settings-open` opens Settings folded, with focus on its heading, and closes it with Esc and with Close, focus back on the Settings button.
- `settings-escape` closes Settings with one Escape while the hidden chat's Folder popover is open.
- `settings-editor-escape` folds the editor with Escape, keeping Settings open with focus on Change, both before a check and after one fails. The next Escape closes Settings.
- `settings-failed` shows a failed check under the field, with focus back in the field and the current connection still Online.
- `settings-checking` shows a running check, then Cancel stops it and keeps Settings open, folded, with focus on Change.
- `settings-saved` folds on the new machine after a check passes, with focus on Change and the news in a status region.
- `settings-pick` closes Settings and opens the bot picked in the sidebar.
- `settings-pick-checking` closes Settings for a sidebar pick while a check runs, and the check stops.
- `settings-palette` opens the palette in Settings without Open Settings, and a bot picked there closes Settings. Ctrl+N and Ctrl+F do nothing in Settings.
- `settings-palette-focus` puts focus on Change when the palette closes after a check that passed while it was open, since the control it opened over is gone.
- `settings-palette-reconnect` puts focus on Change after a palette pick that leaves Settings up, such as Reconnect.
- `settings-saved-pick` opens a bot picked in the new connection's sidebar after a save, since the window sends the new epoch with it.
- `settings-bot-refused` keeps Settings up when Hermes refuses a bot made from the sidebar, and closes it once Hermes makes one.
- `settings-group` closes Settings for a group chat's row and opens the group, which Settings opens over again and Close goes back to. The New group chat dialog's Escape leaves Settings up, and a group chat made there closes it once Hermes has made it.
- `settings-bot-menu` opens a bot's menu in the sidebar beside Settings. Escape closes the menu and leaves Settings up. Pin, Hide, Show in list, Unpin and Edit… leave Settings up, and Open chat and New chat close it.
- `settings-mode` switches the sidebar to chat mode and back from the Sidebar card.
- `settings-theme` picks Light, Dark and System from the Appearance card. [Theme](./theme.md) holds its recipes.
- `settings-passwords` sets up a bot's password managers from the Password managers card. [Password managers](./password-managers.md) holds its recipes.
- `settings-blocked` shows a blocked link's words and Retry in the connection row, with the banner hidden.
- `settings-narrow` stacks the editor's rows and the segments of each choice, and wraps a long host name, in a 360 px window, with every segment inside its card.
- `settings-forced` draws the picked segment and keyboard focus apart in forced colors.
- `settings-chat-buttons` leaves the chat's Copy, Edit message and Branch from here buttons as `main` draws them, since every Settings style sits under `.settings` or `.setup`.
- `settings-sections` shows each section: General, Permissions, Hermes machine, Usage and About.
- `settings-comma` opens Settings with Ctrl+Comma from the chat.

## How to get to it (user POV)

- With a saved connection, press Settings in the top bar, or press Ctrl+K and pick Open Settings.

## Gotchas

- `--hold-at ssh` holds the live remote connection's own probe too, so a running check is pinned from a saved `local` connection.
- The hidden chat's top bar still names the machine, as "on this computer", so a `see` of a machine name can match hidden text first. Prove the editor folded with `count button Connect 0` or `gone button Connect`.
- A passing check on a new machine starts a new epoch, which remounts the window. The sidebar is empty until the new connection lists the bots again.
- `wait settings` passes while the Settings heading is shown, whatever the card's state.
- The fake tailnet holds only the fake machine, so any other name fails at the peer step with "No machine called … is on your tailnet."
- No run reaches main's refusal of an open during a save. The save is main's own file write, and no `--hold-at` holds it. `apps/desktop/test/connection.test.ts` covers that refusal, and `apps/desktop/test/palette.test.tsx` covers the palette coming back for it. No run reaches main's refusal of a pick sent for an older connection either: a window sends one only in the moment before the new connection's setup push reaches it.
- A modal dialog, such as the palette or New bot, makes the rest of the page inert, so a `count` of the Settings heading reads 0 while one is open. Count it after the dialog closes.
