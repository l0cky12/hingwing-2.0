# Settings

The [Hermes button](./hermes-button.md) at the foot of the sidebar, Ctrl+Comma, or Open Settings in the Ctrl+K palette, opens Settings over the whole window. A `--fixture` run has no connection to change, so its Hermes button is off. The bots or chats sidebar hides while Settings is open and comes back after Close as it was, with its search kept. Settings has a nav at its left and a page at its right, with Close at the right of the bar above the page. The nav holds the "Settings" heading, a "Search settings" field and twelve pages: Connection, Models, Appearance, Composer, Window, Notifications, Password managers, Skills, Permissions, Keyboard shortcuts, Usage and About. Settings opens on Connection every time, with focus on the Settings heading. A page shows its title, a line about it, and one card of rows. Connection's card names the machine Highwing talks to: its short name, the full name in mono when it says more, and an Online pill, or the link's own words in place of the mono line with the banner's Retry, Start Hermes or Sign in. Change opens the editor in the same card: "Where Hermes runs" as SSH, Web or This computer, the field the picked one asks for, "SSH destination" or "Gateway address", and a footer with Cancel and Connect. [Connect by URL](./connect-by-url.md) covers the web address. Under the card, "Add a way in" and "Add a server" open the same editor, and [Servers and ways in](./servers-and-ways.md) covers what they add: the ways of a server, the Pick, and the Servers list. A check shows its step in the footer, and a failure shows its alert under the field while the current connection stays Online. Cancel folds the editor, or stops a check. Escape in the editor does what Cancel does while the form takes input, so the first Escape folds it and the next closes Settings. A check that passes folds the editor on the new machine, puts focus on Change and says "Highwing now uses the Hermes on <machine>." Appearance holds Theme, with System, Light and Dark, as [Theme](./theme.md) covers, Accent, seven round tiles (Bot, Ink, Slate, Plum, Olive, Mauve and Umber), where Bot tints the open chat with its bot's color, "Show the bot’s work", with Replies only, Actions and Everything, as [Show the bot's work](./show-work.md) covers, and "Show in the sidebar", with Bots and Chats. Below those, Appearance holds a row for each kind of text: Interface font (menus, settings and replies), Prompt font (the message box and the messages you send), Code font (code blocks, diffs and file paths) and Terminal font (command output and the command an approval card asks about). Each row has a font menu, "Default (Schibsted Grotesk)" or "Default (JetBrains Mono)" first and then every family `queryLocalFonts` lists, a size menu in px, and a live sample under the row. The Code and Terminal rows add a "Wrap long lines in code blocks" or "Wrap long terminal lines" switch under the sample. Changes to files always wrap, as they did before, off and on at first, as code and command output always drew. A row whose pick differs from the default shows a reset button beside its label. Then come Chat width (Narrow, Comfortable, Wide, Full width), Contrast (a 50 to 150 percent slider), Render math (a switch, on at first, and off shows each formula as its TeX between `$` or `$$`) and Animations (a 0 to 400 ms slider, 150 at first, where 0 stops every animation). Contrast and Animations show a reset button once moved. Every pick is kept in `appearance.json` and holds across a restart. At the defaults the chat draws pixel for pixel as it did before these rows existed. Composer holds two switches: Send with Ctrl+Enter, off at first, as [Send a message](./send-a-message.md) covers, and Check spelling, on at first, as [Spell check](./spell-check.md) covers. Window holds "When the window closes", with Quit and Keep in the tray, as [Tray](./tray.md) covers. Notifications holds a switch for each kind of desktop notification, as [Notifications](./notify.md) covers. Password managers sets up 1Password and Bitwarden for each bot, as [Password managers](./password-managers.md) covers. Skills lists the open bot's skills, as [Skills library](./skills-library.md) covers. Permissions says commands are approved on the composer, and lists the open bot's denied commands, the `approvals.deny` rules of its `config.yaml`. Keyboard shortcuts starts with All shortcuts, whose Show all button opens the shortcut sheet, as [Keyboard shortcuts](./keyboard-shortcuts.md) covers, then lists every shortcut of that sheet, each with a line that says where it works. Usage shows what Hermes reports, or that this Hermes does not report usage. About shows the app version and the Hermes version. Every page but Password managers, Skills and Usage, and the Permissions page's list of denied commands, which ask Hermes each time they show, stays mounted while another shows, so an address half typed into the editor is still there after a page switch or a search. Typing in the search field shows "Search results": the rows of every page whose words hold each typed word, under their page's name. Each nav page with a match shows its number of matches. A search that matches nothing says "No settings match" with the words, suggests another word, and offers Clear search. Escape in the field clears a search first, and the next Escape closes Settings. A cleared search goes back to the page that was open. While a check runs or after one fails, a page or a search that hides the Connection card shows a notice, "Highwing is checking the new connection." or "The new connection failed its check.", with Show connection, which opens Connection and puts focus on its title. The nav's Connection carries a dot for the check while its card is out of sight. Close or Esc goes back to the chat and puts focus on the Hermes button. Ctrl+Comma leaves Settings open when it is already open. A popover left open in the chat Settings hides, such as Folder, leaves Escape to Settings, and is still open when the chat comes back. A palette pick of a bot or chat closes Settings and opens it, and so do a notification click and a chat link. Main closes Settings before any open, and stops a running check as Close does. While it saves a new connection it refuses the open, and nothing moves: the palette comes back with its query and main's reason. A palette pick that leaves Settings up, such as Reconnect, puts focus on Change, never on the composer Settings hides. Ctrl+N and Ctrl+F do nothing in Settings. Main refuses a chat command the window sent for an older connection, so a pick sent before a save never reaches the new machine. The connection banner and the preview pane stay hidden while Settings is open.

## Sub-features

- `settings-open` opens Settings on Connection, with focus on its heading and the sidebar hidden, and closes it with Esc and with Close, focus back on the Hermes button. It opens on Connection again after Appearance was showing.
- `settings-escape` closes Settings with one Escape while the hidden chat's Folder popover is open.
- `settings-editor-escape` folds the editor with Escape, keeping Settings open with focus on Change, both before a check and after one fails. The next Escape closes Settings.
- `settings-failed` shows a failed check under the field, with focus back in the field and the current connection still Online.
- `settings-checking` shows a running check, then Cancel stops it and keeps Settings open, folded, with focus on Change.
- `settings-saved` folds on the new machine after a check passes, with focus on Change and the news in a status region.
- `settings-sidebar` hides the sidebar while Settings is open, and brings it back after Close with its search words and results unchanged.
- `settings-pick-checking` closes Settings for a palette pick while a check runs, and the check stops.
- `settings-palette` opens the palette in Settings without Open Settings, and a bot picked there closes Settings. Ctrl+N and Ctrl+F do nothing in Settings.
- `settings-palette-focus` puts focus on Change when the palette closes after a check that passed while it was open, since the control it opened over is gone.
- `settings-palette-reconnect` puts focus on Change after a palette pick that leaves Settings up, such as Reconnect.
- `settings-saved-pick` opens a bot picked in the palette after a save, since the window sends the new epoch with it.
- `settings-group` opens Settings over a group chat, and Close goes back to the group, whose composer still sends.
- `settings-mode` switches the sidebar to chat mode and back from the Appearance page. The sidebar picked shows after Close.
- `settings-composer` turns on Send with Ctrl+Enter and turns off Check spelling from the Composer page, and both stay as set across a restart. [Send a message](./send-a-message.md) and [Spell check](./spell-check.md) hold its recipes.
- `settings-theme` picks Light, Dark and System from the Appearance page. [Theme](./theme.md) holds its recipes.
- `settings-show-work` picks how much of the bot's work the chat shows from the Appearance page. [Show the bot's work](./show-work.md) holds its recipes.
- `settings-appearance-text` picks a code font size and a chat width from the Appearance page, and both hold across a restart.
- `settings-appearance-contrast` draws every diagram after Contrast moves to 150 percent.
- `settings-appearance-parity` leaves the chat pixel for pixel as `main` draws it while every Appearance row is at its default.
- `settings-search` finds rows across pages with their counts in the nav, shows the empty state and its Clear search, and clears with the first Escape and closes with the second.
- `settings-pages` keeps an address half typed into the editor across page switches and a search.
- `settings-away` tells of a failed check from Appearance, marks Connection in the nav, and Show connection opens Connection with focus on its title.
- `settings-away-checking` tells of a running check from Appearance, and Show connection leads back to its Cancel.
- `settings-models` picks a bot on the Models page and reads its default and backup models, Research's with the line for the backup Hermes holds after it. A default model saves at once, a guarded one asks for a second yes under the row and saves on Use anyway, a backup saves at once with the rest of the chain kept, and No backup clears them all.
- `settings-passwords` sets up a bot's password managers from the Password managers page. [Password managers](./password-managers.md) holds its recipes.
- `settings-blocked` shows a blocked link's words and Retry in the connection row, with the banner hidden.
- `settings-narrow` stacks the nav above the page in a 360 px window, wraps the editor's segments and a long host name, and keeps every segment inside its card.
- `settings-forced` draws the picked segment and keyboard focus apart in forced colors.
- `settings-chat-buttons` leaves the chat's message action rows (Copy, Edit message and More actions) as `main` draws them, since every Settings style sits under `.settings` or `.setup`.
- `settings-sections` shows the Window, Notifications, Permissions, Usage and About pages.
- `settings-usage` shows the usage lines a fixture cans.
- `settings-comma` opens Settings with Ctrl+Comma from the chat.

## How to get to it (user POV)

- With a saved connection, press the Hermes button at the foot of the sidebar ("Hermes on hermes-host, Connected"), press Ctrl+Comma, or press Ctrl+K and pick Open Settings.

## Gotchas

- `--hold-at ssh` holds the live remote connection's own probe too, so a running check is pinned from a saved `local` connection.
- The hidden chat's top bar still names the machine, as "on this computer", so a `see` of a machine name can match hidden text first. Prove the editor folded with `count button Connect 0` or `gone button Connect`.
- The hidden sidebar still holds every bot's name, and `see` waits on the first match, so `see Research` in Settings waits on the hidden row and times out. Click the palette's option instead, as `settings-saved-pick` does.
- A passing check on a new machine starts a new epoch, which remounts the window. The sidebar is empty until the new connection lists the bots again, and `wait bots` cannot see it while Settings hides it.
- `wait settings` passes while the nav's Settings heading is shown, whatever the page or the card's state.
- "Connection" names the page's title (a level 2 heading), the nav's page button and the card's region, so pick the role. The title takes focus, so `click heading Connection` focuses it. Click `region Connection` to leave no control focused.
- A nav button's name carries its count in a search, as "Appearance (1 match)", and the check's state, as "Connection (checking)" or "Connection (check failed)". Name it in full.
- The fake ssh answers only at the fake machine's two names, so any other name fails at the ssh step with "Highwing can't reach … over SSH."
- No run reaches main's refusal of an open during a save. The save is main's own file write, and no `--hold-at` holds it. `apps/desktop/test/connection.test.ts` covers that refusal, and `apps/desktop/test/palette.test.tsx` covers the palette coming back for it. No run reaches main's refusal of a pick sent for an older connection either: a window sends one only in the moment before the new connection's setup push reaches it.
- A modal dialog, such as the palette, makes the rest of the page inert, so a `count` of the Settings heading reads 0 while one is open. Count it after the dialog closes.
